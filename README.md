# Каталог автомобилей и запчастей

## О проекте

Проект представляет собой каталог автомобилей и запасных частей, который позволяет узнать, какие автомобили представлены в каталоге и какие запчасти для них доступны.

Основная цель — упростить поиск запчастей для конкретных автомобилей, систематизировать информацию об их наличии и собирать статистику по отсутствующим деталям.

## Возможности

- **Каталог автомобилей** — просмотр списка автомобилей и подробной информации о каждом из них.
- **Каталог запчастей** — просмотр доступных запасных частей и информации о них.
- **Совместимость запчастей** — возможность определить, для каких автомобилей предназначена конкретная запчасть.
- **Учёт отсутствующих запчастей** — ведение списка деталей, которых не хватает для определённых автомобилей, с возможностью дальнейшего анализа спроса.
- **Предложения пользователей** — возможность предложить добавление нового автомобиля или запчасти в каталог.

## Планируемые задачи

- [ ] Создание, просмотр, редактирование и удаление автомобилей.
- [ ] Создание, просмотр, редактирование и удаление запчастей.
- [ ] Указание отсутствующих запчастей для каждого автомобиля.
- [ ] Добавление предложений пользователей по новым автомобилям и запчастям.
- [ ] Систематизация информации о доступности запчастей.
- [ ] Сбор статистики по отсутствующим запчастям.

## Цель проекта

Создать удобный каталог, объединяющий информацию об автомобилях и запчастях, упрощающий поиск необходимых деталей и позволяющий определять, какие запчасти наиболее востребованы, но отсутствуют в каталоге.
